# Life.Studio

**Design the life you actually want.** A static, fully responsive life-design platform: 6 interactive tools, 10 guides, a video library, free coach matching (lead-gen), challenges with prizes, donations, careers and advertising. Built to be monetised with AdSense, YouTube, lead generation, sponsorships and reader support.

- **Live (GitHub Pages):** https://webworksa1.github.io/life-studio/
- **Domain inquiries:** https://web.works/contact

## Stack
Plain HTML + CSS + vanilla JS. No framework, no backend. Hosted free on GitHub Pages, which renders the shared layout with its built-in Jekyll on every push (no CI or paid plan needed).

## Structure
```
_config.yml, _layouts/    ← Jekyll config + shared layouts (header, domain bar, footer, article)
index.html, *.html        ← thin page wrappers (front matter + include of src/…)
assets/css/style.css      ← design system (light + dark)
assets/js/config.js       ← ALL monetisation switches (AdSense, GA4, YouTube, donations, contest)
assets/js/main.js         ← forms, ads, consent, videos, modals, countdown, etc.
assets/js/tools.js        ← the 6 interactive tools
src/pages/*.html          ← page sources (JSON meta on line 1)
src/articles/*.html       ← guide sources (JSON meta on line 1)
sitemap.xml               ← generated by Jekyll from all pages
gen_jekyll.py             ← regenerates layouts + wrappers after adding pages/guides
build.py                  ← optional flat-HTML export for non-Jekyll hosts (run it in a copy: it writes to the root)
docs/STRATEGY.md          ← concept, revenue model, 25-site benchmark
docs/BUILD-PROMPT.md      ← phase-wise master build prompt
```

## Editing
- Change page content in `src/pages/*.html` or `src/articles/*.html` and push. GitHub Pages rebuilds in about a minute.
- New page or guide: add the source file, run `python3 build.py && python3 gen_jekyll.py`, copy `_jekyll_out/*` to the root, then push.

## Go-live checklist
1. **Forms:** submit any form once on the live site. FormSubmit sends a one-time activation email to the site inbox. Click it, and every form (leads, donations, contest, careers, ads) starts delivering.
2. **AdSense:** once approved, set `adsense.client` and slot ids in `assets/js/config.js`, and fill in `ads.txt`.
3. **Analytics:** set `ga4` in `config.js` (loads only after cookie consent).
4. **Donations:** paste Stripe/PayPal/Ko-fi/Patreon links into `donations` in `config.js`. Until you do, donors use the pledge form.
5. **YouTube:** set `youtube.channelUrl` and edit `youtube.videos` (video ids).
6. **Contest:** edit `contest` (name, deadline, prize pool) in `config.js`, and prize copy in `src/pages/challenges.html`.
7. **Lead magnet:** the popup promises a "Life Design Workbook". Create the PDF and send it with FormSubmit's autoresponse or your email tool.
8. **Custom domain:** add a `CNAME` file containing `life.studio`, point DNS A records to 185.199.108.153 / .109 / .110 / .111, set `siteurl` in `_config.yml` and the sitemap line in `robots.txt`.

## Privacy of the contact address
The site inbox never appears in plain text. It is stored encoded and reversed in `config.js` and assembled only at runtime. Do not replace it with a plain address.
